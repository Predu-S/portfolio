# Como editar este site

O projeto usa React e Vite. Edite `src/content.js` para textos, links e imagens compartilhados entre desktop, tablet e mobile.
A estrutura de cada seção está em `src/components/`. Há componentes separados por largura para preservar o design original.
Coloque ajustes visuais em `public/custom.css`. Rode `npm run build` após qualquer alteração.
O site não carrega o runtime do Framer; não há hidratação restaurando valores antigos.
